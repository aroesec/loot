# Screenshots

Every figure in these images comes from a **synthetic household** — invented
merchants, invented amounts, invented accounts. None of it is anyone's real
statement data, which [AGENTS.md](../../AGENTS.md) forbids putting in this
repository and which a public README would publish permanently.

They were taken against a scratch database seeded with three months of a
made-up household, on a throwaway instance, at 2× for a retina display and then
compressed with `sharp`.

If you regenerate them, use synthetic data again. The reason is not only
privacy: a screenshot of a real ledger dates badly, leaks a bank, and cannot be
reproduced by anyone else who wants to update it.
